# Contribuindo com o Math Quest

O Math Quest é um produto educacional proprietário da VSA Tecnologia. Contribuições externas dependem de autorização prévia da mantenedora do projeto.

## Princípios
1. A aprendizagem vem antes da pontuação.
2. A experiência deve ser adequada à idade e respeitar a criança.
3. Cada atividade precisa ter um objetivo pedagógico explícito.
4. Erros são sinais para adaptar a explicação, não motivos para punir.
5. Acessibilidade, privacidade e segurança são requisitos.
6. O código deve ser modular, testável e documentado.

## Fluxo de trabalho
- Abra uma issue descrevendo problema, objetivo e resultado esperado.
- Para mudanças relevantes, registre a decisão em um ADR.
- Separe lógica pedagógica de interface e mecânica de jogo.
- Adicione testes para regras matemáticas e comportamentos críticos.
- Execute npm run typecheck, npm run test e npm run build.
- Descreva limitações, riscos e evidências de validação.

## Checklist pedagógico
- [ ] O objetivo de aprendizagem está definido?
- [ ] A atividade ensina ou avalia uma habilidade identificável?
- [ ] O feedback explica o raciocínio?
- [ ] Existe apoio visual quando necessário?
- [ ] A dificuldade é apropriada?
- [ ] A atividade evita pressão excessiva por velocidade?
- [ ] A experiência foi testada em celular?

## Segurança e dados
Nunca envie credenciais, dados pessoais de crianças, informações de saúde, localização ou dados de produção em issues, commits ou logs. Reporte vulnerabilidades de forma privada à mantenedora.
