# Segurança

A segurança e a privacidade de crianças são requisitos centrais do Math Quest.

## Reportar vulnerabilidade
Não publique detalhes exploráveis em issues públicas. Encaminhe o relato pelos canais oficiais da VSA Tecnologia: https://vsatecnologia.com.br/

Inclua, quando possível:
- componente afetado e versão;
- impacto potencial;
- passos mínimos para reproduzir;
- evidências sem dados pessoais ou dados reais de crianças.

## Escopo atual
O MVP é uma aplicação estática, sem autenticação ou backend central. Dados de progresso são mantidos localmente no navegador. Isso não elimina riscos de exposição no dispositivo compartilhado.

Não inclua segredos no código frontend. Qualquer informação embutida em uma aplicação publicada no GitHub Pages deve ser considerada pública.
