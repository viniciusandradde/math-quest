# Features

Cada feature representa uma capacidade de produto e deve manter interface, estado e regras de apresentação separados.

Features planejadas:
- onboarding: apresentação e configuração inicial;
- diagnostic: diagnóstico de conhecimentos prévios;
- multiplication: aprendizagem e prática da multiplicação;
- missions: jornadas e desafios;
- rewards: conquistas ligadas a evidências de aprendizagem;
- parent-dashboard: visão de responsáveis.

Não duplicar regras matemáticas dentro das telas. Regras pertencem ao módulo src/learning.
